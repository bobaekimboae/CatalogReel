# CatalogReel — 한국어 차량 영상 제작기

CatalogReel 콘솔과 플레이그라운드의 화면 흐름을 참고해 만든 한국어 공개 웹 앱입니다. 사진과 차량 정보를 브라우저에 입력해 세로형/가로형 짧은 영상을 만들 수 있습니다.

## 사용하기

1. [CatalogReel 웹 앱](https://bobaekimboae.github.io/CatalogReel/)을 엽니다.
2. **플레이그라운드**에서 차량 사진을 1~20장 올립니다. JPG, PNG, WebP를 지원하며 파일당 최대 15MB입니다.
3. 차량 정보, 영상 비율, 길이, 해상도를 확인하고 **영상 생성**을 누릅니다.
4. 미리보기에서 재생을 확인한 뒤 MP4 또는 WebM 파일을 저장합니다.

## 로컬 개발

```sh
npm ci
npm run dev
```

정적 배포 파일을 만들려면 `npm run build`를 실행합니다. 결과물은 `dist/client/`에 생성됩니다. GitHub Actions가 `main` 브랜치의 변경을 GitHub Pages에 배포합니다.

## 영상 생성과 데이터 처리

- 업로드 사진은 서버로 전송하지 않고 현재 브라우저 탭에서만 사용합니다.
- 지원 브라우저에서 WebCodecs를 쓸 수 있으면 MP4로 인코딩하고, 그렇지 않으면 MediaRecorder로 WebM을 만듭니다. 최신 Chrome/Edge 사용을 권장합니다.
- 현재 렌더러는 사진 전환, 느린 확대/이동, 세로/가로 화면, 차량명·가격·주행거리·브랜드명·선택한 판매 포인트·CTA를 영상에 합성합니다.
- 앱은 새로고침하면 생성 목록과 미리보기가 초기화됩니다. 이 공개 데모에는 로그인, 서버 저장, 결제, 크레딧, VIN 조회, 매물 페이지 자동 가져오기가 연결되어 있지 않습니다.
- 화면의 AI 나레이션·음악·장면 연출·일부 고급 옵션은 편집 설정으로 표시되지만 현재 렌더러에서 음성/음악 트랙이나 생성형 장면을 만들지 않습니다. 해당 기능은 CatalogReel의 승인된 API와 서버 측 비밀키를 연결해야 합니다. 비밀키를 공개 프런트엔드나 이 저장소에 넣지 마세요.
- 브라우저 성능과 코덱 지원에 따라 렌더링 시간·출력 포맷이 달라질 수 있습니다. 1080p / 긴 영상은 기기 메모리를 많이 사용할 수 있습니다.

## 기술

React, Vite, Mediabunny(WebCodecs MP4), MediaRecorder(WebM), GitHub Pages.
